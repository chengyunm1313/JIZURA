# JIZURA 字面｜歌詞動態影片自動編排工具

**其他語言：** [日本語說明](README.md) · [English guide](README.en.md) · [Bahasa Indonesia](README.id.md) · [한국어 안내](README.ko.md) · [Tiếng Việt](README.vi.md)

**開啟應用程式：**[繁體中文](https://852wa.github.io/JIZURA/zh-hant/) · [English](https://852wa.github.io/JIZURA/en/) · [日本語](https://852wa.github.io/JIZURA/) · [简体中文](https://852wa.github.io/JIZURA/zh-hans/) · [한국어](https://852wa.github.io/JIZURA/ko/) · [Bahasa Indonesia](https://852wa.github.io/JIZURA/id/) · [Tiếng Việt](https://852wa.github.io/JIZURA/vi/)

**版本：v0.9.0**（請參閱[變更紀錄](CHANGELOG.zh-Hant.md)）

輸入歌詞後，JIZURA 會組合歌詞動態影片（文字 PV）常見的版面、動態、裝飾、轉場與畫面效果，自動編排片段並匯出影片。工具內含 860 個演出部件與 27 種風格；每次都會重新組合，換一個種子就能產生不同編排。另附 After Effects（AE）面板，有指令碼版和可直接在 AE 中使用瀏覽器版介面的 CEP 版。

**不需安裝即可使用：**[開啟繁體中文版](https://852wa.github.io/JIZURA/zh-hant/)。一般編輯與匯出都在瀏覽器中處理，不會傳送歌詞或歌曲到伺服器。另有選用的 AI MV 流程：只有你在本機明確同意後，才會把歌詞與本機抽取的音樂特徵傳給 OpenAI API；不會上傳音訊、影片或檔案路徑。應用程式只會在需要時向 Google Fonts 載入目前使用的字型。

- 按「隨機生成一版」（快捷鍵 `R`），即可一次更換風格、氛圍、動態、配色與編排。
- 支援 16:9、9:16、4:3、3:4、1:1、4:5、21:9；720p 至 4K；24、30、60 fps。
- 載入歌曲後會偵測節拍並對齊片段，也可手動點按同步。
- 可匯出含歌曲的 MP4、PNG 序列圖、透明 PNG，也能匯出供 AE 編輯的 JSON 編排資料。
- 可選綠幕或黑底，輸出白色文字與效果，方便合成。

## 系統需求

- **匯出 MP4：**使用支援 WebCodecs 的瀏覽器，建議 Chrome 或 Edge。Safari 16.4 以上、Firefox 130 以上也支援 WebCodecs，但能否匯出 H.264 仍取決於瀏覽器與作業系統。不支援的環境仍可預覽及匯出 PNG 序列圖。
- 手機也可使用：iPhone 需 iOS 16.4 以上的 Safari；Android 建議使用 Chrome。長歌曲或高解析度匯出建議使用電腦。
- 字型會按需從 Google Fonts 載入；離線時會改用電腦上的替代字型。

## 隨機生成與簡易模式

使用右上角的「簡易／進階」切換介面。初次開啟會進入簡易模式；手機會進入手機模式。

按「隨機生成一版」（也可按 `R`）會重新挑選下列項目並從頭播放：

- 風格（不會連續選到相同風格）
- 氛圍（故障風、沉靜、流行、圖像、編輯、情緒、綜合；開啟恐怖效果後也會加入恐怖氛圍）
- 標題與明體框線字型
- 配色（有時也會隨機更換強調色與偏移色 A/B）
- 片段編排（種子）

「上一個方案／下一個方案」可切換隨機產生的版本；「只改這一項」則可保留目前成果，只重新挑選風格、配色、氛圍或編排。歌詞、歌曲、時間點與匯出設定不會因此改變，鎖定的句子也會保留。

### 隨機挑選的演出範圍

在隨機生成按鈕下方（進階模式中位於「手法」分頁上方）可設定隨機生成、洗牌及逐句重新抽選時會使用哪些部件。

- **也使用新增的特效**（預設關閉）：開啟後，會加入首次公開版之後新增的 351 個部件、12 種風格與 6 款字型；關閉時只使用首次公開版的 356 個部件與 12 種風格。
- **也使用日式特效**（預設開啟）：包含燈籠、明信片、障子、扇子、家紋、青海波、櫻花花瓣等圖像，以及「櫻花」「墨與朱」風格。
- **使用文字排版部件**（預設開啟）：50 個以線條、數字與文字編排為主的部件，例如大字夾排、裁切大字、十字編排、注音、框線編排、字級變化、字寬對齊、文字分割與句中強調。
- **使用動態文字部件**（預設開啟）：51 個以逐詞動態為主的部件，例如堆疊、直角轉向、交換、潛入文字、流動排列、逐詞切片、齒輪、正面碰撞與逐詞節拍。有歌曲節拍時，詞語切換會與節拍對齊。
- **也使用恐怖特效**（預設關閉）：52 個詭異氛圍部件與 3 組配色，例如廢墟、深夜錄影、詛咒信件等。開啟後隨機氛圍會加入「恐怖」；恐怖部件只會用在恐怖氛圍中，不含血腥或傷口畫面。
- 以上三組專屬開關與「新增特效」分開；即使「新增特效」關閉，仍可使用這些部件。手動指定句子或自行選風格時，不受隨機挑選開關影響。
- 「手法」分頁與風格清單會以「新增」「和」「恐」標示部件；目前不會被隨機選用的項目會淡化顯示。

### 手機模式

在窄螢幕或觸控裝置上，右上角可切換「手機／簡易／進階」模式。首次開啟時會進入手機模式。

- 隨機生成按鈕固定在頁面上方，捲動畫面時仍可使用。
- 預覽固定在上方，方便隨時檢視。
- 句子清單預設收合；點選句子後才會顯示該句的重新抽選、鎖定與片段數等控制項。點選標題可收合或展開歌詞、句子清單與設定區。
- 儲存、開啟、初始化等功能集中在「選單」，按鈕適合觸控操作。
- 預設匯出解析度為 720p；即使選擇高於 1080p，手機模式也會以 1080p 匯出。更高解析度請切換到進階模式。匯出期間畫面不會自動熄滅；切換到其他應用程式不會被誤判為匯出失敗。支援的瀏覽器可在匯出後使用「分享並儲存」。

## 隨機配色

在「進階」→「風格」分頁的「強調色與偏移色」中調整。

- **隨機配色**會重新組合強調色與色彩錯位用的 A/B 色。
  - 接近一半會從已調校的配色組合中挑選，其餘會依色相環產生新組合。
  - 會根據背景亮度自動調整顏色，保持文字易讀；強調色與背景的對比至少為 3。
- 也可直接選擇顏色。取消勾選「改用自訂顏色」即可還原風格原本的配色。

## 瀏覽器版操作方式

### 1. 輸入歌詞

每行輸入一個樂句，可使用以下記法：

- `黎明的顏色/我還記得`：以 `/` 指定片段切點。
- `*透明*`：強調文字，較容易套用放大或強烈演出。
- 行尾加上 `!`：加入閃光與震動。
- `歌詞|註解`：在註解版面顯示較小的文字。
- `[01:23.45]歌詞`：直接使用 LRC 時間戳記。
- `[間奏 8]`：設定 8 秒間奏，不顯示歌詞，只呈現背景、裝飾與畫面效果。間奏至少 6 秒時會小字顯示曲名與演出者。省略秒數時為 4 秒，可透過點按同步或標記調整長度。`[interlude]`、`[间奏]`、`[간주]` 也有相同作用。

### 2. 載入歌曲與調整時間

- 載入歌曲後會自動偵測 BPM 與節拍，並讓片段切點靠齊節拍。歌曲會保存在這個瀏覽器中，重新開啟頁面時會載入，以免匯出影片時漏掉音訊。
- 按「點按同步」開始播放歌曲，並在每行開始時按 `Space`。按錯可按 `Backspace` 或「退回一步」。按句子清單中的 ◎ 可從該句重新點按同步，前面句子的時間點會保留。
- 也可直接修改句子清單中的秒數。
- **時間軸：**拖曳上方刻度可移動句子的起始時間（預設吸附節拍；按住 `Shift` 可自由調整）。使用 `+`／`−` 或滑鼠滾輪縮放；按住 `Shift` 滾動可左右移動；按「全部」回到全覽。
- 歌詞或時間點的變更可用「復原」或 `Ctrl+Z` 撤銷。

### 3. 逐句編輯

簡易模式也能使用逐句編輯功能。

- 按 ✎ 或雙擊歌詞即可直接修改該句，也可使用上述記法。
- 以「片段數：自動／1～6」設定一句切成幾段。
- 按句子旁的骰子，只重新抽選該句；按鎖頭固定該句編排。進階模式可直接指定版面。鎖定後，即使重新抽選其他句或按隨機生成，該句的版面、動態、裝飾、配色與片段切法都會保留。
- 按「洗牌」重新抽選全篇。
- **逐片段替換（進階模式）：**點選預覽下方的片段資訊（版面、進場、停留、退場、裝飾、文字加工、背景、鏡頭或轉場），即可只替換該片段的部件；選「自動」可還原。也可在句子清單中指定版面，或按「隨機生成此片段」重新抽選。替換不會改變其他片段的抽選結果。
- **鎖定（進階模式）：**在「手法」分頁鎖定各類部件的開關狀態，或在「特效」分頁鎖定滑桿、閃光與逐格動畫設定。鎖定內容會保存在專案檔中。
- **循環播放：**按播放按鈕旁的「循環」，依序切換全篇、句子、片段與關閉。循環句子或片段時，時間軸會標出循環範圍。

### 4. 風格、字型與效果

- 共有 27 種配色、字型與質感組合，包括櫻花、深海、夕陽漸層、森林手帳、Vaporwave、報紙、合成器 80 年代、牛皮紙、糖果、酸性風格、墨與朱、金夜，以及廢墟、深夜錄影與詛咒信件等恐怖風格。背景可能依片段切換。
- 可選用 Google Fonts 的 18 個字型家族，包括 Reggae One、Rampart One、Potta One、Kiwi Maru、Klee One、Shippori Mincho B1。只會載入目前編排使用的字型。
- 可輸入電腦已安裝的字型名稱，或載入 `.ttf`、`.otf` 字型檔。
- 在「特效」分頁調整動態強度、故障效果、色彩錯位、裝飾數量、片段密度、質感與逐格動畫。
- 在「手法」分頁開啟或關閉 10 類部件：版面、進場、停留、退場、裝飾、文字加工、背景、鏡頭、畫面效果與轉場。可依分類收合，並使用「全部開啟／全部關閉／反轉」及名稱篩選。

### 5. 匯出

可匯出含歌曲的 MP4、PNG 序列圖（ZIP）、透明 PNG（ZIP）。畫面比例支援 16:9、9:16、4:3、3:4、1:1、4:5、21:9；解析度支援 720p 至 4K；影格率支援 24、30、60 fps。

- **只匯出選定句子：**在「匯出範圍」設定起訖句，或按句子清單中的 ⇥；按住 `Shift` 點選可擴大範圍。檔名會附上句子編號，例如 `_L03-05`。
- 影片會分段寫入，減少長歌曲或 1080p、1440p 匯出時的記憶體用量。若 GPU 編碼器失敗，會自動改用軟體編碼器重試。
- Chrome／Edge 可先選擇目的檔案，再直接寫入，適合長歌曲或高解析度匯出。
- 若瀏覽器無法以 AAC 匯出音訊（例如只能輸出 Opus 或無法輸出音訊），iPhone 或 QuickTime 可能無法播放聲音；此時也會另存同長度的 WAV 音訊。

### 統一感與文字排列

- **統一感：**依文字 PV 常見方式編排。每個段落（以空行區分）會統一版面、動態、鏡頭與裝飾；重複歌詞（例如副歌）會沿用第一次出現時的呈現方式。動態方向交替安排，強烈效果留給重點句。
  - 行尾加 `!` 的句子會以單一片段強調；若沒有標記，則強調重複段落的開頭句，並加入大字、閃光、縮放與震動。
  - **字形轉換：**相鄰片段會讓相同字形移動，其他字形則溶解轉換。
  - **字重變化：**部分字型會由細逐漸變粗。
- **文字排列：**縮小假名間距與助詞，放大句首字與英文字，並在日文與英文之間留出間距。文字會比人聲提早 0.2 秒顯示，並限制疊加效果（最多一個裝飾、每片段最多一種畫面效果）。
- 取消勾選即可維持原本編排方式。AE 面板會套用選定版面、動態與時間點；字距、字級、字重與字形轉換會以相近效果呈現。

### 保留中央空間供角色使用

在「匯出」設定中開啟「保留畫面中央」。橫式畫面會把歌詞分成左右兩側，直式畫面則分成上下兩區，例如「花開了」可拆成「花開」｜「了」。橫式畫面兩側各約佔畫面寬度 36%（21:9 為 30%）；直式畫面各約佔高度 33%。兩側共用同一組版面、動態、裝飾與鏡頭，後半段稍晚出現。背景與畫面效果仍覆蓋全畫面，不會使用放大單字背景。短到無法分割的句子會在兩側重複顯示。直式畫面可選擇上下或左右排列；選左右時，每區寬度為 34%。預覽以虛線標出保留區域，匯出檔不含虛線。AE 指令碼版、CEP 版與 JSON 匯出也支援此設定。

### 固定版面、清除與初始化

- 螢幕寬高足夠時，預覽與時間軸會固定在中央；歌詞清單與設定分別在左右欄內捲動。播放時清單會跟隨目前句子，但手動捲動後會暫停跟隨。窄螢幕仍使用整頁捲動。
- 「清除歌詞」會清除歌詞、逐句時間點、逐句指定與匯出範圍，可用「復原」或 `Ctrl+Z` 還原。
- 標題列的「初始化」會清除歌詞、歌曲（包括保存在此瀏覽器的歌曲）、設定、方案歷史與復原紀錄，確認後即無法還原。顯示模式、預覽音量與介面語言會保留。

### 匯出給 After Effects

選擇「匯出至 AE」即可把目前的時間點、版面、演出與配色匯出為 JSON。載入 AE 面板後，可用相同編排建立可編輯的合成。

### 首次使用導覽、介面語言與預覽音量

- 首次開啟時，簡易模式會依序導覽歌詞、歌曲、隨機生成、播放、逐句編輯與匯出。按「？」可再次開啟；使用方向鍵切換，按 `Esc` 結束。
- 介面支援日文、英文、印尼文、越南文、繁體中文、簡體中文與韓文。不同語言使用相同的專案檔格式；非日文介面會以英文顯示演出部件名稱。
- 播放控制旁的音量滑桿只調整預覽音量；「音量」按鈕可靜音或解除靜音。設定會保存在瀏覽器中，不會改變匯出的 MP4 音量。

## AI MV Motion Graphics Engine：單曲 MVP

此流程保留原本瀏覽器編輯器與匯出功能，另外建立可供 JIZURA、本機 AI 工具和 FFmpeg 共用的 MV Timeline v1。背景影片由外部生成後匯入；本機工具不呼叫影片生成服務，也不會分析影片畫面。

1. 在「匯出」分頁展開 **AI MV Motion Graphics Engine**。先在 JIZURA 載入歌曲、歌詞和一段以上的背景影片，再建立 MV 專案資料夾。歌曲、影片、時間軸和 Style／轉場目錄會複製到你選定位置；原始檔不會修改。
2. 在 JIZURA 專案原始碼資料夾開啟 Terminal，檢查專案：

   ```sh
   python3 tools/mv_engine.py validate "/完整路徑/歌曲-mv"
   ```

3. 若要使用 AI，先把 OpenAI API 金鑰存入 macOS Keychain，再為這次請求明確加上同意旗標：

   ```sh
   python3 tools/mv_engine.py keychain-set
   python3 tools/mv_engine.py ai-plan "/完整路徑/歌曲-mv" --consent-lyrics-features
   ```

   AI 建議會建立 `timeline.proposed.json`，不會覆寫核准版 `timeline.json`。請回到 JIZURA 開啟專案資料夾，載入並審核建議；可調整段落、Style、進入段落的轉場、影格範圍、鏡頭來源和描述，也可鎖定段落，再按「核准並儲存時間軸」。鎖定段落的範圍及相鄰邊界都會固定。不使用 AI 時，也可以直接手動編輯並核准。
4. 核准後按「輸出透明圖層至專案」。瀏覽器會逐格輸出 `render/mg/back/` 與 `render/mg/front/` PNG，不會把全曲影格累積在記憶體中。
5. 確認本機已安裝 FFmpeg，且 `ffmpeg`、`ffprobe` 可從 Terminal 找到，再合成：

   ```sh
   python3 tools/mv_engine.py render "/完整路徑/歌曲-mv" --approved
   ```

   輸出為 `render/final.mp4` 和 `render/render-manifest.json`。工具會檢查尺寸、影格率、片長、音軌並完整解碼；缺少 FFmpeg 時會停止並提示，不會自動下載或安裝。

時間以輸出影格編號表示，區間使用 `[startFrame, endFrame)`。歌曲段落、歌詞、節拍、背景鏡頭與轉場皆使用同一影格基準；影片來源裁切另以微秒記錄。AI 只能使用專案 `catalog.json` 中的既有 Style 與轉場識別碼，鏡頭文字只是供人對照素材的建議。

AI 請求只傳送歌詞、節拍／能量特徵、輸出影格設定及可選用的 Style／轉場目錄；不傳音訊、背景影片、素材檔名或本機路徑。AI 金鑰只存於 macOS Keychain，不寫入專案包或日誌。每次 AI 請求都必須有 `--consent-lyrics-features`；核准版與透明圖層狀態也會在渲染前再次檢查。

完整欄位、範例 JSON、轉場對應與操作細節請見[繁體中文 MV Timeline v1 指南](docs/MV_TIMELINE_v1.zh-Hant.md)。

## 24／30／60 fps 匯出

1. 在「匯出」分頁（簡易模式位於右側「匯出」區）選擇畫面比例、解析度與 fps。
2. 按「匯出 MP4」。例如 6 秒影片在 24 fps 下為 144 格，在 60 fps 下為 360 格。
3. 動作的逐格感由「特效」分頁中的「逐格動畫」設定決定，與輸出 fps 分開：
   - **一拍二（12 格／秒）：**文字 PV 常見的微頓動態；不同輸出 fps 看起來相同（預設）。
   - **一拍三（8 格／秒）：**更像手繪動畫，停頓感較明顯。
   - **完整：**每個輸出影格都會更新動態；60 fps 搭配完整模式最流暢。
4. 故障與閃爍效果以 24 fps 為基準，改成 60 fps 不會讓閃爍加速。
5. YouTube 或 MV 建議使用 24 或 30 fps；社群直式影片若需要流暢動態，可用 30～60 fps 搭配完整模式。60 fps、4K 匯出需要較多時間。

AE 面板可在「fps」設定中選擇 24、30 或 60。從 JSON 建立時，會沿用瀏覽器版選定的 fps。

## 合成用背景：綠幕、黑底與透明 PNG

在「匯出」分頁的「背景」中選擇一般、綠幕或黑底。綠幕使用 `#00FF00`，黑底使用 `#000000`，兩者都只繪製白色文字與效果。設定會同步套用到預覽與匯出檔；檔名會附上 `_greenback` 或 `_blackback`。

- 綠幕可用 Premiere Pro Ultra Key、DaVinci Resolve 3D Keyer 或 AE Keylight 等色度鍵去背。
- 黑底可使用「濾色」（或加亮）混合模式疊加，或用亮度鍵去除黑色。
- 透明 PNG 可直接作為透明前景使用。

**透明 PNG 前景／後景（ZIP）**會將每格輸出成兩張透明 PNG：`back/` 放背景圖像與歌詞後方裝飾；`front/` 放歌詞、周邊裝飾與框線、色彩錯位殘影及 HUD。全畫面效果會同時套用兩層；將 `front` 疊在 `back` 上即可還原一般畫面。背景色、紙張質感、發光與掃描線不會輸出。

透明 PNG 不會填入背景色；全畫面效果只作用在文字與裝飾上。文字、裝飾與效果會轉為白至灰的單色；風格配色、背景圖樣、紙張質感、粒子與暗角不會輸出。色彩錯位殘影與光暈會以灰階呈現，去背後成為半透明效果。若不需要全畫面閃光，可在「特效」分頁關閉閃光、降低故障效果，或在「手法」分頁關閉個別畫面效果。AE 面板與 AE JSON 也支援相同背景設定。

## 歌詞語言與字型替換

各風格原本以日文字型為主。輸入繁體中文、簡體中文或韓文時，若字型缺少部分字形，可能會在同一句中混用不同字型。可在歌詞欄下方的「歌詞語言」中切換。

- **自動偵測（預設）：**含假名時判斷為日文；含韓文時判斷為韓文；只有漢字時，則依「們／们」「說／说」等字判斷繁體或簡體中文。
- 可手動指定日文、繁體中文、簡體中文、韓文或英文。
- 歌詞幾乎全為英文字母時會判斷為英文；英文會以每 2～3 個單字為一組切分片段。若使用 `/`，則依指定位置切分。

## After Effects 面板

AE 面板有兩種，使用相同的演出引擎：

AE 面板提供日文與英文版；以下將操作名稱翻成中文，實際顯示名稱會依面板語言而不同。

- **指令碼版（`JIZURA_AE.jsx`）：**可從歌詞建立合成，也能載入瀏覽器版匯出的 JSON。
- **CEP 版（`JIZURA_CEP.zip`）：**可在 AE 中直接使用瀏覽器版介面與預覽，按「AEでコンポを生成」（在 AE 建立合成）即可建立合成。

### 指令碼版安裝

1. 將 `JIZURA_AE.jsx` 放進對應資料夾並重新啟動 AE。
   - Windows：`C:\Program Files\Adobe\Adobe After Effects <版本>\Support Files\Scripts\ScriptUI Panels\`
   - macOS：`/Applications/Adobe After Effects <版本>/Scripts/ScriptUI Panels/`
2. 在「視窗」→「JIZURA_AE.jsx」開啟面板並停駐。
3. 試用時也可用「檔案」→「指令碼」→「執行指令碼檔案」開啟浮動面板。

### 指令碼版使用方式

- **從歌詞建立：**輸入歌詞並選擇風格、尺寸與效果，再按「建立合成」。時間點可依字數與 BPM 自動計算，也可使用選取圖層標記或合成標記。
- 建議先選歌曲圖層，播放時用數字鍵盤的 `*` 為每句開頭加標記，再勾選「使用選取圖層標記作為句首」。
- **隨機生成：**每次會隨機決定風格、氛圍、效果強度、二拍一／閃光／HUD、種子與配色，並建立新合成。可再微調後重新建立。
- **氛圍：**只從符合氛圍的版面、進場與退場部件中選用。同一種子會得到相同結果。
- 可設定強調色與偏移色 A/B，也可輸入 `#RRGGBB`。勾選「覆寫風格顏色」後會套用至所有場景，亮度會依背景自動調整。
- 可設定新增特效、日式特效、文字 PV、動態文字、恐怖效果與一般／綠幕／黑底背景。27 種風格都可選用；清單以「新增」「和」「恐」標記。
- **部件支援：**860 個瀏覽器版部件會以 AE 文字圖層、形狀圖層、遮罩、效果與運算式組成。歌詞保持為文字圖層，可事後修改。3D 旋轉、翻紙與像素級加工會以 AE 內建效果和 2D 變形呈現近似效果。
- 若 JSON 包含面板尚未支援的部件，會替換為最接近的部件，並在狀態列顯示「已替換」。
- **尺寸：**1920×1080、1080×1920、1080×1080、3840×2160、1280×720、1440×1080（4:3）、1080×1440（3:4），或沿用目前作用中的合成尺寸。
- **從 JSON 建立：**載入瀏覽器版匯出的 AE JSON，即可在 AE 建立相同編排。
- **字型：**AE 2024 以上可自動選用已安裝的字型；否則可在「字型」分頁指定。預設使用游ゴシック與游明朝。
- **輕量模式：**略過色彩錯位複製、紙張質感、光暈、粒子及複製影像效果，圖層約減少四成。
- **長曲：**分批建立合成，避免 AE 顯示「沒有回應」。按「中止」會以已完成片段建立合成；重做時請在專案面板刪除合成與 `cuts` 資料夾。
- **診斷報告：**在「從 JSON」分頁可讓 AE 計算最後建立合成的運算式，並輸出 `JIZURA_report.txt`，列出錯誤與替換項目。

### CEP 版安裝與使用

1. 下載並解壓縮 [`JIZURA_CEP.zip`](https://852wa.github.io/JIZURA/JIZURA_CEP.zip)。
2. macOS 執行 `install_mac.command`；Windows 執行 `install_win.bat`。安裝檔會複製面板至目前使用者的 CEP 擴充功能資料夾，並設定 Adobe PlayerDebugMode，讓 AE 載入未簽署面板。
3. 重新啟動 After Effects 2022 以上版本，在「視窗」→「擴充功能」→「JIZURA 字面」開啟面板。

歌詞、風格與演出設定方式和瀏覽器版相同。可指定匯出句子範圍、分析所選歌曲圖層並依 AE 標記設定句首時間點，也可直接匯出 MP4 與 PNG 序列圖。詳情請參閱[CEP 面板繁體中文說明](cep/dist/README_CEP.zh-Hant.md)。

### AE 面板會建立的內容與注意事項

每個片段會建立預合成並放入 `JIZURA <曲名> cuts` 資料夾。文字會保留為文字圖層，修改文字後仍可保留動態。最上方的 `JZ FX` 調整圖層會包含二拍一、震動、切片故障、縮放模糊、反相、光暈與雜訊；另會建立 `JZ Flash`、`JZ Vignette` 與 HUD。
AE 2020 以上的運算式引擎須使用 JavaScript。面板曾在模擬 AE 物件模型的環境中驗證，但尚未在實際 AE 軟體中執行。部件多的片段會產生較多圖層與運算式；長曲建立與預覽可能較久，可將預覽解析度降為 1/2～1/4。

## 開發與建置

```sh
python3 build.py              # src/ app/ vendor/ → 各語言的 index.html
node tools/export_ae_data.js  # 修改 src/ 後更新 AE 面板使用的樣式與部件資料
python3 build_ae.py           # 建置 JIZURA_AE.jsx
python3 build_cep.py          # 建置 CEP 面板資料夾與 JIZURA_CEP.zip
```

版本號記錄在根目錄 `VERSION`；建置時會寫入瀏覽器版、AE 面板與 CEP 版。更新版本時也請修改 `CHANGELOG.md`。可執行 `python3 tools/fold_readme.py README.md`，依 `<details>` 區塊收合 README 的標題。
建置只需要 Python 3 與 Node.js，不需要 npm 套件。AE 面板測試需要先在 `dev/` 執行 `npm install`，再執行 `node dev/ae_test.js`。新增演出部件時請參閱[繁體中文部件開發指南](docs/EXPRESSION_PACKS.zh-Hant.md)，測試工具位於 `dev/`。

### 發布到自己的 GitHub Pages

若要在自己的 fork 發布：

1. 將根目錄含有 `index.html` 的版本推送到 GitHub。
2. 在 **Settings → Pages** 將 Source 設為 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`。
3. 等候數分鐘，再前往 `https://<使用者名稱>.github.io/<儲存庫名稱>/`。
